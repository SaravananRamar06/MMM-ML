# Team 8 examination and defence pack

Prepared 17 November 2026 for the entire JC-PINN / ANSYS bracket project. This is teaching material, not a new experiment or a change to the submitted model.

## Read in this order

For a book layout, start with the [textbook edition](../../output/pdf/project-textbook.pdf): numbered chapters and equations, linked contents, PDF bookmarks, notation, figures, viva and exercises. It uses the same audited lesson sources as the shorter guides below.

1. [Study handbook](../../output/study/study-handbook.md): material science, continuum mechanics, FEA, the neural material law, ANSYS integration, interpretation and derivations.
2. [Viva bank](../../output/study/viva-bank.md): demanding questions with defensible answers and follow-up challenges. Cover the answer and speak before reading it.
3. [Exam and presentation workbook](../../output/study/team-workbook.md): worked calculations, a timed mock exam with marking guide, a slide-by-slide rehearsal and a team preparation schedule.
4. [Interactive practice](../../output/study-practice.html): offline flashcards with topic filters and self-assessment. Open in a browser; no installation or data upload.

Printable versions are in [output/pdf](../../output/pdf/). All numerical placeholders in the teaching sources are resolved by `scripts/build_study_pack.py` from `report/numbers.json`. Install `requirements-study.txt`, then rebuild with `.venv/Scripts/python.exe scripts/build_study_pack.py`. The sources use `{{NumberKey}}` for saved project results; the generated guides and PDFs contain the actual values. No saved model result is changed.

Then run `.venv/Scripts/python.exe scripts/build_study_textbook.py` for the textbook. ReportLab handles pagination, contents and bookmarks; Matplotlib MathText typesets the display equations. Windows Georgia, Arial and Consolas fonts are used. The scientific audit and its corrections are recorded in [audit.md](audit.md).

## Authority and reading conflicts

Use `docs/decisions.md`, `docs/open-questions.md`, the lock errata and the newest saved study for current status. Some earlier guides still say units were inferred, ANSYS had not run, G(phi) was unknown, or the mesh/EP study was pending. Those statements are superseded: units and the density interpretation are user-confirmed; ANSYS has run; D5 assumes a G(phi) relation; two-mesh USERMAT and hardening-EP studies exist. Generator documentation and experimental validation are still absent.

The original 4% study uses G = 24541 MPa. The later D5 coupled-porosity study uses G = 24288 MPa at 4%. Keep those two conditions distinct.

## External teaching references

These support general theory, not experimental claims about our bracket. Later ANSYS documentation explains the API concepts; the actual project evidence is for MAPDL 2024 R1.

- [ANSYS: Customizing Material Behavior](https://ansyshelp.ansys.com/public/Views/Secured/corp/v261/en/ans_prog/Z7K4r1e5lcd.html): USERMAT returns stress and a consistent material Jacobian, and needs tests under several loading conditions.
- [ANSYS: consistent tangent matrix](https://lsdyna.ansys.com/the-consistent-tangent-matrix-2/): tangent consistent with the discrete return algorithm.
- [Primary AlSi10Mg microstructure / heat-treatment study](https://www.nature.com/articles/s41598-021-85047-2): process, microstructure and mechanical property relationships. The handbook's short metallurgy discussion is general background; our project has no microscopy.

## What everyone must be able to do

Explain the complete chain: processing and pores -> assumed effective properties -> material-point stress update -> FE equilibrium -> bracket reaction -> limits on interpretation. Derive the J2 return residual, explain why softening needs a length scale, explain lambda = 0, and distinguish numerical verification from physical validation. Individual contributions must be described truthfully; the suggested speaking roles do not establish authorship.
