# Course report and shared LaTeX sources

| File | What it is |
|---|---|
| `report.pdf` / `report.tex` | Course report on the final JC-PINN model, its use as a finite-element material on the bracket, and the bracket's critical flaw length (24 pages). |
| `numbers.tex` | Every number quoted in the report, paper and slides, generated by `scripts/write_latex_numbers.py` from `reports/jc_pinn_20261107/` and, for the finite-element and critical-flaw-length sections, from `umat/` and `bracket/ansys_usermat/` (including `crack2d_2026-11-20/`). Do not edit by hand. |
| `numbers.json` | The same values, for the slide builder. |
| `refs.bib` | Bibliography shared with `paper/paper.tex`. Every entry was checked against its DOI, publisher page or arXiv record. |

The IEEE-format paper is in [`../paper/`](../paper/paper.pdf). Figures come from [`../figures/`](../figures), written by `scripts/make_figures.py`.

## Rebuild

```bash
python scripts/make_figures.py
python scripts/write_latex_numbers.py
cd report && latexmk -pdf report.tex && cd ../paper && latexmk -pdf paper.tex
```

To get LaTeX on Debian or Ubuntu, install `texlive-latex-extra`, `texlive-publishers` (for IEEEtran), `texlive-science` and `latexmk`.

On Windows with MiKTeX and no Perl, `latexmk` does not run. Use `pdflatex`, then `bibtex`, then `pdflatex` twice, in each folder. The PDFs of 18 Nov 2026 were built this way with MiKTeX 25.12 (report 21 pages, paper 5 pages). The PDFs of 22 Nov 2026, which add the critical-flaw-length section, were built with TeX Live 2023 and `latexmk` (report 24 pages, paper 5 pages).
