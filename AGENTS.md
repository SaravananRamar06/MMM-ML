## User rule: commit all project work to GitHub

Commit and push code, tests, documentation, research decisions and relevant
verification evidence before ending each work turn. Use focused commits and
verify that origin contains them. Respect the existing exclusions for raw data,
credentials, environments, downloads and scratch files. Preserve uncommitted
work that does not belong to the current task. Report the pushed commit IDs.
